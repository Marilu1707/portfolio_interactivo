## Portfolio Interactivo de Data Science [GitHub](https://github.com/Marilu1707/portfolio_interactivo)

- Aplicación interactiva en Flutter Web (Dart) desplegada en Vercel que gamifica conceptos de Data Science: desde la recolección de datos (juego de pedidos) hasta la comunicación de insights (dashboard ejecutivo).
- Implementé EDA interactiva con fl_chart, modelo de ML online (regresión logística con descenso de gradiente estocástico), y módulo de A/B testing con Z-score, p-value e intervalos de confianza.
- Diseñé un sistema de gestión de inventario con semáforos visuales y un dashboard ejecutivo con KPIs, tasas de cumplimiento e insights automáticos.
- Arquitectura con Provider para gestión de estado, internacionalización (i18n), y diseño responsive adaptado a desktop y mobile.
